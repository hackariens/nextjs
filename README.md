## Need

Software:

- [task](https://taskfile.dev/)
- [nodejs](https://nodejs.org/)
- [lampy](https://github.com/koromerzhin/lampy)

Config:

docker swarm

Hosts:

- nextjs.traefik.me

## Download

```sh
git clone --recursive git@github.com:hackariens/nextjs.git nextjs
cd nextjs
```

## Environnment

Edit .env with .env.example

## Create apps

```sh
task create:apps
```

## Launch

``` sh
task nextjs:exec
```
